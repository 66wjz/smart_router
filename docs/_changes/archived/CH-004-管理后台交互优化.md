## 一、变更背景

维护迭代阶段用户反馈 4 个问题：
1. 上游源页面需要能选择模型做连通性测试（新功能）
2. API Key 管理：点击「生成随机 Key」会突然刷新页面（bug）；且生成应自动完成，Key 旁提供「重新生成」按钮
3. API Key 管理操作列按钮（修改/禁用/复制/删除）粘连在一起
4. 全系统按钮/输入框/下拉框高度不统一

## 二、详细设计

### 2.1 模型测试（FB-003）

- 后端：`POST /admin/api/upstreams/{upstream_id}/test`，入参 `{model, prompt?}`，走 Key 池 + 非流式适配器转发，返回 `{ok, content}`
- 前端：上游源模型列表标题区新增「测试选中模型」按钮，对勾选模型发起测试，弹窗展示回复

### 2.2 生成随机 Key 刷新页面 bug（FB-004）

- 根因：`BaseButton` 渲染的 `<button>` 未指定 `type`，默认 `submit`，在 `el-form` 内点击触发原生表单提交导致页面刷新
- 修复：`BaseButton` 全局加 `type="button"`（顺带防止其他页面同类问题）
- 交互优化：打开新增弹窗自动生成随机 Key 并填入表单；Key 输入框旁增加「重新生成」按钮

### 2.3 API Key 操作列按钮间距（FB-005）

- 操作列按钮包 `flex` 容器并加 `gap: 8px`，列宽 280→320

### 2.4 全局控件统一高度（FB-006）

- 根因：Base 组件 default 高 36px，Element Plus 默认 32px，混排参差
- 方案：`--control-height` 36→32px，与 Element Plus（el-input/el-select/el-button）默认高度对齐；`--control-height-sm` 28px 保留给列表操作区紧凑按钮（上游源管理样板不变）
