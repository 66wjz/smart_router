## 四、方案

### 4.1 删除 v4 遗留

按 3.1 清单删除；同步删除 `README.md` 文档索引里的 `config.example.yaml` 一行。

> `router.py` 依赖的 `core/`、`upstream/`、`admin/` 与它一起删，不留半套。

### 4.2 登记 `auto_same_name` 待办

在 `docs/需求规格.md` 增加一节「待完善事项」，写明：
- 现状：`auto_same_name_enabled()` 有定义但**无任何调用点**，设置页也无开关；同名模型跨源聚合**恒开启**
- 原计划：CH-019 承诺「设置页加开关，可一键回退旧行为」
- 影响：不影响当前使用（聚合本就按顺序跨源兜底）；缺的是「关闭兜底」的能力
- 后续：待完善时按 B 线-小处理（前后端各一处：设置页开关 + `collect_group_members` 判断）

同时在 `docs/数据库设计.md` 3.9 的说明里已注明该键为「未生效的预留键」（CH-029 已加），本次不重复改。

### 4.3 补 `smart-retry` API 文档

- `docs/API契约.md`：新增 `GET/PUT /admin/api/config/smart-retry` 小节（路径、入参、出参、默认值、语义）
- `docs/接口文档.md`：补同端点的一行说明
