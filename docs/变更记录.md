## 2026-10-17（CH-023）

### 聚合模型统一化 + 探测模板 + 探测排班表（B 线-大，本地实现未部署）

**变更内容**：

- **聚合实体统一**：新表 `agg_unified` 用 `kind` 区分两类聚合——`static`（固定成员，原 `agg_model_group`，支持异名成员）与 `rule`（规则匹配，原 `agg_aggregated_name`）。旧表数据由幂等迁移自动搬入，旧表保留不删做回滚兜底
- **探测模板**：新表 `agg_probe_template`。模板 = 一套可复用探测节奏（间隔 / 慢阈值 / 排序 / 时段）。聚合挂模板后，模板值完全覆盖自配字段（不可被组覆盖）；改模板即所有引用方同步生效；删模板则引用方 `template_id` 置空并回退自配 → 全局
- **rule 聚合纳入探测计划**：探测对象为「所有路由规则候选的并集」，聚合名形式的候选继续展开为各源真实模型名；探测单元上记录 `groups` 与 `group_kinds`，排班表能看出单元被谁拉起
- **探测排班表**：聚合页新增「探测计划」标签，按小时展示每个单元何时探测（`██` 探测中 / `░░` 时段外 / `──` 关闭），支持「合并视图 / 按星期」切换，行尾给出间隔、次/时、次/日与引用聚合；支持跨夜窗口
- **路由排序行为保持不变**：rule 聚合继续走 `get_ordered_candidates`（priority + 动态权重，即 `base_weight × (base_latency / latency)²`），探测结果仍参与排序；static 聚合走 `sort_group_candidates`（stable/latency 分层，全 down 回退配置顺序）。两者不互斥
- **信息架构归位**：侧边栏移除「延迟面板」「路由参数」，聚合模型改为三标签（聚合组 / 探测模板 / 探测计划）；请求重试 / 智能重试 / 故障转移搬到「系统设置 → 全局容错」；全局探测默认值并入探测计划；`/latency` → `/aggregated?tab=plan`、`/route-params` → `/settings` 兼容重定向
- **兼容旧接口**：`/admin/api/model-groups*`、`/admin/api/aggregated-names`、`/admin/api/model-groups/probe*` 全部保留并转调新实现

## 2026-10-17（CH-021）

### 聚合模型独立探测（全局去重）+ 探测时段 + 两档智能排序 + 用量按单元记账（B 线-大，本地实现未部署）

**变更内容**：

- **探测单元全局去重**（核心）：探测对象 = `(上游源, 该源真实模型名)` 的并集，来自「路由规则候选 ∪ 别名目标 ∪ 聚合组成员」，全局唯一。多个聚合组共享同一模型时**只探一次**；多组引用同一单元时间隔取最小值
- **聚合组独立探测策略**：新表 `agg_probe_config`，每组可独立配 启用开关 / 间隔 / 慢阈值 / 排序模式 / 探测时段；留空跟随全局。与 `agg_model_group` 解耦，自动发现的组也能配，且不会变成"已手动配置"
- **探测时段（新增需求）**：支持 `always` 全天候 或 `window` 按星期（1~7，空=每天）+ 时段窗口（可多条，支持跨夜如 `23:00→07:00`）配置，用于"夜间不探测 / 周末不探测 / 只在工作时间探测"。时段外不探测但保留旧数据；多组引用同一单元时任一组在时段内即探测
- **调度改造**：从「全局 `sleep(interval)` 全量探」改为「按单元到期调度」，每个单元按自己的间隔独立计时；`asyncio.gather` + 信号量限流（`max_concurrency` 默认 5）
- **两档智能排序**：`stable`（层内保持人工拖拽顺序）/ `latency`（层内按实时延迟升序）。分层 T0 正常 → T1 偏慢/未知 → T2 down/冷却；**全部候选不可用时回退配置顺序**，绝不返回空候选
- **探测与 Key 冷却解耦**：探测的超时/401/429 默认**不计入** Key 冷却（`count_key_failures` 默认 false）。原行为在只有一个上游 Key 时，3 个模型同时超时会把唯一 Key 打进 120s 冷却，导致期间所有真实请求失败
- **用量按单元记账**：`log_usage` 补 `upstream_model` 列（实际命中的上游真实模型名，异名聚合时与请求名不同），新增 `GET /admin/api/usage/by-unit` 按「源 × 真实模型」聚合，为号池积分配额核算打底（自动关停留给 CH-022）
- **前端**：聚合页组卡片探测徽标 + 设置弹窗（含时段与三个快捷模板）+ 全新「探测计划（全局去重）」表（带去重节省数与每日探测成本）；路由参数页补慢阈值/并发数/Key 冷却开关/全局时段；用量页新增「按单元」表
