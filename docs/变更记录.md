### 后台交互补齐 + 聚合列表拖拽排序（A 线 + B 线-中）

**背景**：用户提出 5 项问题——①分组管理的「+ 添加分组」没像「新建聚合」那样在右上角，配色也不同；②全局容错三个保存按钮没对齐；③路由规则「修改规则」弹窗里不能直接选模型；④路由规则 YAML 编辑只有一个 textarea，不好操作；⑤聚合模型列表希望可拖动调整顺序。

**分类（铁律 7）**：③为 A 线（下拉框该出现却没出现，接口选错）；⑤为 B 线-中（新增持久化能力）；①②④为 B 线-小（布局与交互形态调整）。

**根因定位**：

- ② `Settings.vue` 三段 `el-form` 的 `label-width` 不一致（请求重试/故障转移 140px、智能重试 160px）；保存按钮在无 label 的表单项里，左边界 = label 宽度，实测 x 分别为 364 / 384 / 364。

- ①②④ 属纯布局/交互形态，无代码缺陷。

**变更内容**：
